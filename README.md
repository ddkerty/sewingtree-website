# Sewing Tree — test website

v2.2 static website preview for linen_s_t / 쏘잉트리.

Site: https://ddkerty.github.io/sewingtree-website/

GitHub Pages publishes the root of main. Push changes to main to update the site.

Local preview: run python -m http.server 8000 and open http://localhost:8000.

812 blog records and 7,581 remote image references; covers are local. Original photos require network access. New posts are not synced automatically. Photos and clothing designs belong to their respective owners.

This is a public test deployment with search indexing discouraged via noindex.
